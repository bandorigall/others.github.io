[결정사항]
- ★API 키(.env)는 절대 커밋 금지★ 배포 리포는 others/ 이다. 최상단 "[] 홈피_깃헙io"가 아님.
  한 번 착각해서 바깥 .gitignore에 넣었다가 키가 공개될 뻔했음. others/.gitignore 로 차단 완료.
  푸시 전 확인: cd others && git ls-tree -r --name-only HEAD | grep -E "\.env$"  (결과 없어야 정상)
- 기온 숫자는 이미지와 index.html 양쪽에 존재. 반드시 update.py로 함께 갱신할 것(어긋남 방지).
  이미지에만 두지 않은 이유 = 스크린리더/검색 노출 + 예보 변경 시 텍스트만 고치면 됨.
- 4번 "그늘로 옮기고": 우산을 그리면 "우산을 씌워라"로 오독됨.
  → 그림에서 소품을 전부 빼고 normalize.py가 인물 뒤에 연한 면(SHADE)을 코드로 깔아 그늘 표현.
  prompts.json 패널에 "shade": true 를 주면 적용. AI에 음영을 맡기지 않는 이유 = 매번 뿌옇게 나옴.
- 준비물에서 이온음료(캔) 제외: 공연장 캔·병 반입금지 가능성. 소금사탕도 반려됨.
  → 양산·우산으로 확정(반입제한 없음 + 그늘 확보 + 강수확률 49% 대응).
- 준비물 패널(05_kit) 추가 근거: 픽토그램은 "동작"보다 "사물"에서 오독이 없다. 단 한글 라벨 필수.
- 부연설명은 이미지 안에 넣지 않는다. 훑는 속도가 죽어 "안 읽는 글"이 됨. 필요하면 이미지 밖 텍스트로.
- 한글은 AI에 맡기지 않고 PIL로 로컬 합성(맑은고딕 Bold). 공짜 + 무한 수정 + 깨짐 없음.
- 색 규칙: 파랑=대처행동, 빨강=위험/환자, 검정=일반 인물.
- 오독 방지: 1·3번에 태양 심볼(더위 맥락), 3번에 땀방울(→"술 취한 사람"으로 읽히는 것 차단).
- 스타일: ISO 7001 비상구 러닝맨 계열 플랫 실루엣. 얼굴·텍스트·그라디언트·테두리 금지.
- 모델 gpt-image-1 / 1024x1024. 기본 quality=low로 충분(픽토그램은 납작한 도형).
  API에 "프로 모드"는 없고 quality=high가 최상이지만 이 용도엔 불필요.

[함정 기록]
- normalize.py 팔레트 스냅의 거리계산은 반드시 int32.
  int16이면 제곱합(최대 195075)이 오버플로해서 색이 통째로 반전된다. 실제로 한 번 당함.
- nav.js의 플로팅 메뉴는 z-index:2147483647(최댓값)이라 오버레이를 뚫고 나온다.
  z-index로는 못 이기므로 body.lb-open 클래스로 숨기는 방식 사용.
- 리포 루트에 남은 빈 폴더 "[] 홈피_깃헙io/김치쿠라"는 access denied로 삭제 실패. 수동 삭제 필요.
