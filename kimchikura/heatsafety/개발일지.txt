[결정사항]
- 4번 "그늘로 옮기고": 우산/파라솔을 그리면 "우산을 씌워라"로 오독됨.
  → 그림에서 소품을 전부 빼고, normalize.py가 인물 뒤에 연한 면(SHADE)을 코드로 깔아 그늘을 표현.
  prompts.json 패널에 "shade": true 를 주면 적용됨. AI에 음영을 맡기지 않는 이유 = 매번 뿌옇게 나옴.
- 준비물에서 이온음료(캔) 제외: 공연장 캔·병 반입금지 가능성. 소금사탕도 반려.
  → 양산·우산으로 확정(반입제한 없음 + 그늘 확보 + 강수확률 49% 대응).
  ※ 생수 페트병도 막는 공연장이면 "생수" 항목 재검토 필요. 주최측 공지 미확인 상태.
- 준비물 패널(05_kit) 추가 근거: 픽토그램은 "동작"보다 "사물"에서 오독이 없다.
  단 물병/이온음료는 실루엣이 겹치므로 캔 형태로 구분 + 한글 라벨 필수.
- 부연설명은 이미지 안에 넣지 않는다. 훑는 속도가 죽어 "안 읽는 글"이 됨. 필요하면 이미지 밖 텍스트로.
- normalize.py 팔레트 스냅 시 거리계산은 반드시 int32.
  int16이면 제곱합(최대 195075) 오버플로로 색이 반전됨. 실제로 한 번 당함.
- 한글은 AI에 맡기지 않고 PIL로 로컬 합성(맑은고딕 Bold). 공짜 + 무한 수정 + 깨짐 없음.
- 픽토그램 4장 고정: 01_hydrate / 02_shade_rest / 03_warning_signs / 04_help_call.
- 스타일: ISO 7001 비상구 러닝맨 계열 플랫 실루엣. 얼굴·텍스트·그라디언트·테두리 금지.
- 색 규칙(2차 개정): 파랑=대처행동, 빨강=위험/환자, 검정=일반 인물.
  순수 흑백에서 변경한 이유 = 훑어봐도 위험 패널이 즉시 구분되게.
- 오독 방지 장치: 1·3번에 태양 심볼(더위 맥락), 3번에 땀방울(→"술 취한 사람"으로 읽히는 것 차단).
- API 키는 .env에만. 공개 github.io 리포이므로 절대 커밋 금지.
  환경변수명은 OPENAI_KEY (OPENAI_API_KEY도 fallback으로 인식).
- 모델 gpt-image-1 / 1024x1024 / quality=high. API에 "프로 모드"는 없고 quality=high가 최상.
